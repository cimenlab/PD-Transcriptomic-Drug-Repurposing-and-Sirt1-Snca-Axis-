# PD-Transcriptomic-Drug-Repurposing-and-Sirt1-Snca-Axis-
Transcriptomic drug repurposing analysis across 33 GEO datasets (postmortem, iPSC, and cell-based Parkinson's disease models), integrating differential expression, GO/KEGG enrichment, STRING networks, and DGIdb screening, with SIRT1-SNCA Spearman correlation analysis and resveratrol as a candidate compound.
